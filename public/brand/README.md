# Brand assets

`nit-goa-logo.png` is the original 811 × 115 wordmark downloaded from NIT Goa's official website on 2026-10-06:
https://www.nitgoa.ac.in/static/logo_color_5.png

The landing/header/footer frame the emblem through CSS. The source artwork is unmodified. Its rights remain with NIT Goa. This community project describes itself as an independent campus experience.

`favicon.svg` is the project's own N monogram, using the landing-page colours; it is not the institute's emblem.

`google-signin.png` remains the existing Google sign-in button artwork.
