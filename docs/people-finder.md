# People finder removal

The people and location finder was removed on 13 October 2026. The campus no longer shows a finder card, remote-person minimap markers, direction arrows, distances, Find buttons or location-sharing settings. Its entry has also been removed from the visitor update feed.

The normal people roster, public profile links, chat and message mute remain available. Nearby multiplayer avatars and shared football, OAT and café activities continue to use the live campus connection.

Updated clients request hidden locator visibility when they join or reconnect, so older clients cannot use the retired finder to locate them across the campus. The existing server privacy filtering remains compatible with those older clients; nearby avatars remain visible on the same floor. Finder preferences saved in local storage no longer enable any UI.
