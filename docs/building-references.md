These are stylized reconstructions, not measured architectural replicas. The brochure repeats a departmental image under several captions; the shared design family is supported, but every individual elevation is not documented. Entrance orientation is inferred from nearby mapped roads. Talpona's entrance uses the existing usable hostel plan instead, so decoration leaves its opening clear. Heights remain visual estimates, with explicit OSM height/level tags taking priority.

Roof geometry triangulates each actual outer ring and its courtyard holes, then raises interior points using distance from the eaves. Roofs cover the complete mapped shell without sealing courtyards. Window frames and trim are instanced; glass and signage use local procedural geometry and canvas textures. Reference photos are not redistributed as app assets. Night mode lights the glazing; selection, terrain elevation and mapped building IDs remain intact.

The independently saved `relation/19505812/0` also bears the name Ramanujan Complex. It has not been conflated with the owner's CSE footprint. Workshops, faculty quarters, Director's Residence, Zuari GuestHouse, Nescafe, and utility buildings retain generic appearances pending identifiable exterior references. The brochure's canteen photo shows its interior, which cannot establish an accurate exterior facade.
